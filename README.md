# Ask BIONEXT 2.0

Ask BIONEXT 2.0 is an agentic AI prototype for exploring BIONEXT research and project knowledge from approved sources.

The prototype is designed to answer questions using only selected BIONEXT-related sources, including:

- BIONEXT pages on Oppla
- BIONEXT resource pages and linked documents
- selected approved external sources such as CORDIS and IPBES

The app is built with Streamlit and uses controlled retrieval, source restrictions, and citation-aware answering.

## Prototype goals

- Provide a browser-based AI chatbot interface
- Restrict answers to approved source material
- Route questions to relevant source areas
- Extract text from approved web pages and PDFs
- Provide clear source references in responses

Prototype under development.
